# Молодежка — официальные сборки

Приложение для подготовки и проведения молодёжных встреч.

[Скачать последнюю версию](https://github.com/Alex-astfotolab/molodejka-releases/releases/latest)

- Android 10 и новее, ARM64: один APK для телефонов и планшетов.
- Windows 10/11, x64: установщик с выбором папки и ярлыков.

Устанавливайте новую версию поверх предыдущей, не удаляя приложение.
Данные встреч сохраняются отдельно от файлов программы.

Репозиторий содержит только сведения о распространении и релизные сборки.
